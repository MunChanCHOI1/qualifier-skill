# SK하이닉스 예선 작업 가이드

SK하이닉스 AI 해커톤 예선의 허용된 과제풀이를 위한 비공식 Agent Skill입니다. 요구사항과 구현 원리를 먼저 설명하고, 참가자가 확인한 뒤 작업을 요청하면 구현·검증합니다.

주최사·운영사·OpenAI의 공식 자료나 승인된 도구를 뜻하지 않습니다. 공개되어 있다는 사실만으로 대회 반입이나 사용이 허용되는 것은 아닙니다. 실제 응시 규정과 제공 환경의 안내를 먼저 확인하세요.

## 구성

```text
skills/skhynix-qualifier/
  SKILL.md
  agents/openai.yaml
  references/
    requirements.md
    verification.md
    submission-check.md
```

실행 지침은 네 Markdown 파일입니다. `agents/openai.yaml`은 Codex에서 표시할 이름과 호출 예시를 담은 메타데이터입니다. 스크립트, 외부 서비스, 별도 API 키, 특정 모델, 추가 에이전트는 필요하지 않습니다. 지침은 영어로 작성했으며 기본 사용자 응답은 한국어입니다.

기본 흐름은 **요구사항 함께 확인 → 원리 브리핑 → 참가자의 작업 요청 → 구현·검증 → 실제 결과 설명**입니다. 기본 단위는 하나의 기능이나 API이며, 코드 한 줄이나 파일 하나마다 확인받지 않습니다. 참가자가 전체 설계를 확인한 뒤 한 번에 구현하도록 요청하거나 연속 진행을 요청하면 그 범위를 따릅니다. 이미 요청한 범위의 테스트와 일반적인 오류 수정은 추가 확인 없이 진행합니다. 고정된 시간 배분은 없으며 실제 마감과 공식 제출 절차를 따릅니다.

README와 제공 파일은 필요할 때 읽는 근거 자료입니다. 파일 열람을 금지하거나 참가자에게 모든 문서를 읽도록 강제하지 않습니다. 중요한 요구사항의 위치와 의미를 짚어 참가자가 방향을 결정할 수 있도록 돕습니다. AI 활용 방식에 관한 개발자의 코멘트를 공식 감점 규정으로 단정하지 않습니다.

브리핑에서는 목표, 입력부터 결과까지의 흐름, 작은 예시, 선택 이유와 한계, 구현·검증 범위를 보여줍니다. 예를 들어 API라면 요청 주소와 입력값, 서버의 검증·처리 과정, 저장 위치, 성공·실패 응답을 연결해 설명합니다. 개발 용어는 처음 나올 때 풀어 쓰고, 필요하면 짧은 흐름도나 비교표를 사용합니다. 별도의 대시보드나 추가 도구는 필요하지 않습니다.

환경에서 허용한 프로젝트 의존성 설치, 로컬 서버 실행과 테스트는 요청한 구현 범위의 일반 작업입니다. [요구사항 참조](skills/skhynix-qualifier/references/requirements.md)에 브리핑 방법과 비즈니스 질문 예시가 있고, 검증 참조에는 관찰한 결과를 구현 원리와 연결하는 방법이 있습니다. 금지 경계의 기준 문서는 [SKILL.md의 Boundaries](skills/skhynix-qualifier/SKILL.md#boundaries)입니다.

## 사용 범위

- 참가자의 목표와 필요한 파일을 함께 참고해 요구사항과 구현 원리를 설명합니다.
- 설명을 들은 참가자가 자연어로 작업을 요청하면 해당 범위를 구현하고 실제 관찰에 근거해 검증합니다. 이해했다는 말이나 질문만으로 구현 요청을 대신하지 않습니다.
- 구현 후에는 실제 코드와 검사 결과를 연결해 설명하고, 계획·구현·검증 여부를 구분합니다.
- 제출 준비 여부와 남은 한계를 보고합니다. 제출과 최종 확인은 참가자가 수행합니다.
- Computer Use, 화면 자동 조작, 제한 우회, 외부 AI 연결, 작업물 외부 전송·Git Push를 수행하지 않습니다.
- 제출물 확정 전 인계 시점에 AI 작업을 종료합니다. 후속 서술형의 답안·개요·번역·첨삭이나 예상 답변 대본을 만들지 않습니다.

스킬은 모델에 주는 지침이며 기술적인 접근 통제나 규정 준수 보증이 아닙니다. 실제 권한과 사용 가능 도구는 제공 환경이 결정합니다.

## 적용과 호출

공개 저장소: https://github.com/MunChanCHOI1/qualifier-skill

공개 저장소 클론이 허용된 제공 환경에서는 다음 명령으로 가져올 수 있습니다.

```sh
git clone https://github.com/MunChanCHOI1/qualifier-skill.git
```

클론만으로 스킬의 자동 등록이 보장되지는 않습니다. 제공 환경의 등록 방법을 사용하거나, Codex에 `qualifier-skill/skills/skhynix-qualifier/SKILL.md`를 읽고 필요한 참조 파일과 함께 적용하도록 요청하세요.

사용이 허용된 환경에서 `skills/skhynix-qualifier` 디렉터리 전체를 해당 환경의 공식 스킬 적용 방법으로 등록하세요. 참조 파일도 함께 필요합니다. 개인 PC 파일 업로드가 제한된 환경에서는 이 패키지의 로컬 사본이나 ZIP을 업로드하지 마세요. 공개 저장소에서 가져오는 경로도 운영 안내에서 허용될 때만 사용합니다.

적용 후 다음처럼 요청할 수 있습니다.

```text
$skhynix-qualifier
현재는 AI 사용이 허용된 과제풀이 단계입니다.
내 목표와 필요한 과제 파일을 참고해서 요구사항과 구현 원리를 먼저 설명해줘.
API나 기능별로 입력 → 처리 → 결과 흐름, 선택 이유와 한계를 보여줘.
내가 확인하고 작업을 요청하면 그 범위를 구현하고 검증해줘.
```

단계와 남은 시간은 실제 상태에 맞게 전달하세요. 설치 경로, 모델명, 시험 시간, 과제 스택은 이 패키지가 고정하지 않습니다. 스킬이 인식되는지와 참조 문서를 읽을 수 있는지는 허용된 사전 체험에서 확인해야 합니다.

브리핑 후에는 “그 방식으로 구현해줘”, “저장 방식부터 더 설명해줘”, “전체 설계대로 한 번에 구현해줘”처럼 자연어로 진행을 정할 수 있습니다. 별도 승인 문서나 이해도 시험은 요구하지 않습니다. 개발 중 원리를 이해하도록 돕는 것과 후속 서술형 문항의 답안을 지원하는 것은 구분하며, 제출물 확정·문항 준비·서술형 단계 이후의 지원 제한은 유지합니다.

description에 한국어 예선·과제풀이·해커톤 과제 키워드를 포함했습니다. 자동 선택을 보장하지는 않으므로, 사전 체험에서 인식 여부를 확인하고 필요하면 위와 같이 직접 호출하세요.
